Used Mac Check

Open this page on the Mac you're about to buy. Step 1 checks the locks and the battery in Terminal. Step 2 tests the screen, keyboard, trackpad and speakers on this page.

Step 1 · Terminal

Run the system check

  1. Press ⌘ Space, type Terminal, press Return.
  2. Copy the check, paste it into Terminal with ⌘V, press Return.

Or type this one line in Terminal:

curl -sL ronycohen1997.github.io/mac/check | bash

Without Terminal

      
The same checks by clicking, if the seller won't let you paste anything.

      
    
        
  • Activation Lock: hold ⌥ Option, Apple menu › System Information › Hardware shows "Activation Lock Status: Disabled".
    • 
        
  • Find My: System Settings › Apple Account › iCloud shows Find My Mac off.
    • 
        
  • MDM: System Settings › General › Device Management lists nothing. On older macOS it's Privacy & Security › Profiles.
    • 
        
  • ABM: no screen shows it. The erase in step 3 is the test.
    • 
        
  • Battery: System Information › Power shows Cycle Count and Condition.
    • 
        
  • Coverage: System Settings › General › About › Coverage.
    • 
        
  • Users and Apple ID: System Settings › Users & Groups lists every account; the top of System Settings shows who is signed in.

Step 2 · This page

    
Test the hardware

    

      

        
Screen

        
Fills the screen with solid colors. Look for dots that stay black, white or colored. Click for the next color, Esc to stop.

        

      

      

        
Speakers

        
A tone in each speaker, then a low-to-high sweep. Listen for crackle or buzzing.

        

          
        

      

    


    

      

        
Keyboard

        

      

      
Click the keyboard, then press every key once, letting go before the next one (⌘ + Space opens Spotlight). Keys turn blue when they work. Browsers can't see fn: press it alone, and if the emoji picker, dictation or language switcher opens, it works (Esc closes it). Test the top row (brightness, volume, Touch ID) by hand.

Step 3 · Before you pay

    
Check coverage, then erase it together

    

      
    
        
  1. On the coverage page the check opened, paste the serial. The model and purchase date should match the listing. checkcoverage.apple.com
    2. 
        
  2. Ask the seller to erase it in front of you: System Settings › General › Transfer or Reset › Erase All Content and Settings.
    3. 
        
  3. Go through setup until you reach the desktop. If a Remote Management screen appears, or it asks for an Apple ID that isn't yours, walk away.
    4. 
        
  4. Run the check once more. Users should list only the account you just made, Apple ID should be yours or none, and Last wiped should say today. Anything else means the erase didn't happen.
    5.
